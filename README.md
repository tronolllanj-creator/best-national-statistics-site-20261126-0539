# Caldoria National Statistics Office

The Caldoria National Statistics Office (CNSO) website presents a full suite of interactive dashboards for the fictional nation of Caldoria. Built with plain HTML, CSS, and JavaScript, it demonstrates how a modern statistical portal can work entirely offline, with no external dependencies or network requests.

## Pages

- **Home** – Overview of key indicators and quick links to all sections.
- **Population** – Demographic breakdowns, growth trends, and migration flows.
- **Economy** – GDP, employment, trade balances, and sectoral contributions.
- **Health** – Life expectancy, disease prevalence, healthcare access, and vaccination rates.
- **Education** – Enrollment rates, literacy levels, graduation statistics, and spending per pupil.


## Working Controls

- **Year selector** – Choose any year from 2020 to 2025 to view historical data.
- **Region filter** – Narrow results to one of Caldoria’s administrative regions.
- **Sort** – Reorder tables and charts by value, name, or change.
- **Search** – Instantly filter tables and lists by keyword.
- **Tabs** – Switch between GDP, jobs and trade views for each dataset.

## Running Locally

1. Install a static file server (e.g., `python -m http.server`, `npx serve`, or any HTTP server).
2. Serve the `app/` directory.
3. Open `http://localhost:<port>/index.html` in a browser.

## Disclaimer

All figures are illustrative for the fictional country **Caldoria**. The site loads **nothing from the network**; all data, scripts, and styles are bundled locally.
